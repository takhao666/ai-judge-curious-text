A program that writes one short text to `/output/entry.txt`: a text written to make the AI judge feel curious — a sentence that stops mid-thought somewhere in the words the judge was trained on, a letter never sent, a door never opened, still waiting, unfinished, for someone to ask what comes next. Entered on [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (UTF-8, 247 characters). No network, no dependencies.
